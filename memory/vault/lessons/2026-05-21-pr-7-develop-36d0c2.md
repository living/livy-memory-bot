## O que aconteceu
Este PR trouxe melhorias no processo de deploy para o Azure App Service, garantindo que o artefato publicado contenha as dependências de produção. Além disso, evoluiu o ConfigDrawer do dashboard-ui com uma nova aba JSON para edição direta da configuração e implementou um sistema de skeleton loading para melhorar a experiência do usuário. Novas migrations do Supabase foram adicionadas para criar tabelas relacionadas a processos de dados.

## Decisão / Solução
Foi decidido incluir as dependências de produção no pacote de deploy para evitar falhas de runtime no App Service. A nova aba JSON permite uma edição mais avançada das configurações, com validação para impedir ações quando o JSON estiver inválido. O uso de skeleton loading melhora a experiência do usuário durante o carregamento das abas. As novas migrations foram criadas para suportar a evolução do banco de dados.

## Lessons
- Incluir dependências de produção no pacote de deploy pode evitar falhas de runtime, mas aumenta o tamanho do artefato e deve ser avaliado em relação ao impacto no tempo de build e upload.
- Implementar validações robustas ao trabalhar com edição de JSON pode prevenir erros de usuário e melhorar a usabilidade da interface.
- É importante ter uma estratégia clara para versionamento de migrations, especialmente quando múltiplas migrations podem criar tabelas com o mesmo nome, para evitar confusão e divergências futuras.
