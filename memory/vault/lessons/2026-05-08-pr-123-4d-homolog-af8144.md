## O que aconteceu
Este PR adiciona a dependência **`pdf-lib` (v1.17.1)** ao projeto, permitindo funcionalidades de **manipulação/geração/edição de PDFs**. A alteração líquida inclui a nova biblioteca e suas dependências transientes no `package-lock.json`.

## Decisão / Solução
Foi decidido incluir a biblioteca `pdf-lib` para complementar a funcionalidade de leitura já existente com `pdf-parse`, permitindo a criação e edição de PDFs. A inclusão de novas dependências foi feita para suportar essas funcionalidades.

## Lessons
- Sempre confirme se as novas dependências estão refletidas no `package.json` para garantir a consistência em diferentes ambientes.
- Avalie se a nova biblioteca é realmente necessária para o uso pretendido, evitando dependências desnecessárias que podem aumentar o tamanho do bundle.
- Monitore o impacto de novas dependências no tempo de build e instalação, especialmente em ambientes de CI/CD.
