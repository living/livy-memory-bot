## O que aconteceu
Foi discutida e implementada a autenticação para o bucket GCP no contexto do projeto CERC/Billing.

## Decisão / Solução
A solução escolhida envolve a utilização de credenciais de serviço para garantir acesso seguro e controlado ao bucket, permitindo que apenas usuários e serviços autorizados possam interagir com os dados armazenados.

## Lessons
- A autenticação via credenciais de serviço é uma prática recomendada para garantir a segurança em ambientes de nuvem.
- É importante documentar o processo de autenticação para facilitar futuras manutenções e auditorias.
