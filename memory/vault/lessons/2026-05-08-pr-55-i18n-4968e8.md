## O que aconteceu
Este PR introduz a pauta de internacionalização (i18n) no projeto RetailAuditInfraDashboard, preparando a aplicação para suportar múltiplos idiomas. A mudança foi motivada pela necessidade de reduzir hardcodes e facilitar a manutenção, além de permitir a expansão do dashboard para usuários com diferentes necessidades de idioma.

## Decisão / Solução
Foi decidido implementar a internacionalização para padronizar mensagens e centralizar conteúdo textual, melhorando a consistência da interface do usuário. A abordagem inclui a migração de strings hardcoded para arquivos de tradução e a implementação de um fallback de idioma.

## Lessons
- Sempre verifique o acesso ao diff antes de iniciar a documentação de um PR, pois a falta de acesso pode dificultar a validação das mudanças.
- Ao implementar internacionalização, é crucial testar a UI em diferentes idiomas para garantir que não haja textos ausentes ou formatações incorretas.
- Documentar as alterações de forma clara e detalhada ajuda a equipe a entender o impacto das mudanças e a evitar regressões futuras.
