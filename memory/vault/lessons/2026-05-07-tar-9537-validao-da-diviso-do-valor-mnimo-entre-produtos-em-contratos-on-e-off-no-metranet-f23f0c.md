## O que aconteceu
Foi solicitado que, para contratos ON e OFF, a soma dos consumos de produtos diferentes seja considerada. Se a soma não atingir o consumo mínimo, o valor mínimo deve ser dividido entre os serviços.

## Decisão / Solução
O Metranet já aceita a divisão do valor mínimo entre os produtos, não sendo necessário desenvolvimento adicional para implementar essa funcionalidade.

## Lessons
- A validação de regras de faturamento pode evitar desenvolvimentos desnecessários se o sistema já suportar a lógica requerida.
- A comunicação clara entre as partes interessadas (solicitante e equipe técnica) é fundamental para garantir que as soluções existentes sejam utilizadas de forma eficaz.
