## O que aconteceu
Foi implementado o gerenciamento de SKUs no dashboard, incluindo um CRUD completo, upload e remoção de imagens utilizando Azure Blob, além de uma integração configurável por país com uma API externa para autocomplete. A nova funcionalidade também inclui listagem com cards e tabela, ordenação, scroll infinito, e ajustes em permissões e internacionalização.

## Decisão / Solução
A decisão foi criar uma nova área no produto dedicada ao gerenciamento de SKUs, com rotas e permissões específicas. Foram criadas novas tabelas no banco de dados para suportar a funcionalidade, além de serviços para gerenciar a lógica de negócios e integrações com APIs externas. A interface foi projetada para ser intuitiva, com suporte a múltiplos idiomas.

## Lessons
- A implementação de integrações externas deve considerar a segurança, especialmente ao executar scripts dinâmicos, para evitar riscos de execução de código malicioso.
- É importante manter a consistência entre diferentes rotas da API para evitar comportamentos divergentes que possam confundir os usuários.
- Testes abrangentes são essenciais para validar novas funcionalidades, especialmente em sistemas que manipulam dados sensíveis como SKUs e imagens.
