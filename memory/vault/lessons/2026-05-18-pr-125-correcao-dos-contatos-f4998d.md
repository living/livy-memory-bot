## O que aconteceu
Este PR visa ajustar a forma como os contatos são tratados na API. No entanto, não foi possível acessar o diff do PR, o que impede uma análise detalhada das mudanças realizadas.

## Decisão / Solução
Devido à falta de acesso ao diff, não foi possível revisar as alterações nos endpoints ou identificar mudanças no contrato da API. A decisão foi solicitar acesso ao diff para uma análise completa.

## Lessons
- Sempre verifique se o diff do PR está acessível antes de iniciar a revisão.
- Documente claramente as mudanças propostas para facilitar a comunicação entre os membros da equipe.
- Estabeleça um protocolo para garantir que os testes sejam realizados em alterações críticas, como as que envolvem contatos.
