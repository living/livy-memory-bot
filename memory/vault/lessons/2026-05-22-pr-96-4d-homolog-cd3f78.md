## O que aconteceu
Este PR ajusta a atualização da lista de mensagens no **PanelComponent** para sempre normalizar e ordenar o payload recebido, garantindo que o estado do painel seja atualizado de forma consistente, mesmo quando o retorno é vazio ou nulo.

## Decisão / Solução
A solução implementada normaliza o retorno do socket para um array vazio quando necessário, assegurando que o datasource seja atualizado e que a interface do usuário reflita corretamente o estado atual, evitando a exibição de mensagens antigas.

## Lessons
- Sempre normalize os dados recebidos de fontes externas para evitar estados inconsistentes na UI.
- Considere o impacto das mudanças de comportamento na experiência do usuário, especialmente em cenários de dados vazios.
- Valide se as alterações não introduzem efeitos colaterais indesejados, como degradação de performance devido a chamadas frequentes de detecção de mudanças.
