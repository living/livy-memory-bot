## O que aconteceu
Foi realizado um alinhamento sobre a integração entre SVD e Hydra utilizando o plugin Delphys Connect. Foram discutidos aspectos técnicos da arquitetura do fluxo, incluindo o endpoint de consulta de usuários e o ciclo completo de agendamento via WhatsApp.

## Decisão / Solução
Decidiu-se que a versão inicial do plugin SVD usará um número de telefone hardcoded para testes, enquanto a versão V2 integrará dados da API. O workflow será isolado por cliente, e um webhook de retorno será cadastrado para entregar o payload ao Hydra quando o usuário responder.

## Lessons
- A implementação de um número de telefone hardcoded na versão inicial permite testes rápidos, mas é crucial planejar a evolução para integrar dados dinâmicos da API.
- Isolar workflows por cliente ajuda a evitar impactos em outros sistemas, aumentando a segurança e a confiabilidade da integração.
