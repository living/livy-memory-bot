## O que aconteceu
Foi realizado um ajuste na validação de conflito de vigência de garantidora em condomínio, tratando corretamente os casos em que a vigência existente não possui `data_fim`, interpretando-a como "vigente até indefinidamente". Essa mudança evita erros de validação ao considerar `data_fim` nula.

## Decisão / Solução
A lógica foi alterada para que a ausência de `data_fim` seja interpretada como uma data sentinela (2199-12-31), permitindo que o sistema bloqueie corretamente novas vigências que sobreponham esse período. Essa abordagem simplifica a validação e mantém a consistência nas regras de negócio.

## Lessons
- Sempre que uma data pode ser nula, considere a implementação de uma data sentinela para evitar comportamentos inesperados.
- Testes devem ser criados para cobrir cenários de vigências abertas e suas interações com novas vigências.
- Mantenha a consistência no tratamento de datas em todo o sistema para evitar falhas de validação.
