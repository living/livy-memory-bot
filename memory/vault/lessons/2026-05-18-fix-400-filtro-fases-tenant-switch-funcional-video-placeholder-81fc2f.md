## O que aconteceu
Foi realizada uma correção no sistema que abordou o erro 400 relacionado ao filtro de fases, além de implementar a funcionalidade de troca de tenant e adicionar um placeholder para vídeos.

## Decisão / Solução
A equipe decidiu implementar as correções e melhorias necessárias para garantir que o filtro de fases funcione corretamente, que a troca de tenant seja funcional e que haja um placeholder para vídeos, melhorando assim a experiência do usuário.

## Lessons
- A importância de testar as funcionalidades de filtro em diferentes cenários para evitar erros como o 400.
- A necessidade de ter placeholders visuais para melhorar a usabilidade quando conteúdos não estão disponíveis.
