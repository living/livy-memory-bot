## O que aconteceu
Este PR introduz a dependência **`pdf-lib`** no projeto e ajusta o serviço de comunicação **WhatsApp** para melhorar o envio de arquivos e padronizar o estilo/código. A alteração líquida principal é: **melhoria no `sendFile` para usar `arquivo.filename` (ao invés de `arquivo.name`)** + refactors de formatação/legibilidade no `WhatsappService`.

## Decisão / Solução
A decisão foi adicionar a biblioteca `pdf-lib` para permitir a manipulação de arquivos PDF e corrigir o nome do arquivo enviado para a API do WhatsApp, garantindo que o nome correto seja utilizado durante o upload, evitando problemas comuns com nomes de arquivos genéricos.

## Lessons
- Sempre verifique se os atributos esperados de um objeto estão presentes antes de utilizá-los, para evitar regressões em funcionalidades.
- Refatorações de código devem ser acompanhadas de testes que garantam a compatibilidade com entradas antigas.
- A introdução de novas dependências deve ser planejada para que seu uso seja implementado em um PR futuro, garantindo que o código permaneça limpo e focado.
