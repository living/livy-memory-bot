## O que aconteceu
Este PR ajusta o formato de datas enviado ao backend e faz um pequeno refactor na montagem da query string. A mudança líquida principal é que as datas passaram de `dd/MM/yyyy` para `yyyy-MM-dd`, evitando inconsistências na aplicação de filtros por período.

## Decisão / Solução
Foi decidido alterar o formato de data para um padrão mais compatível com APIs (ISO-like) e simplificar a construção da query string no código, mantendo o comportamento esperado e reduzindo a verbosidade.

## Lessons
- Sempre utilize formatos de data compatíveis com o backend para evitar falhas em filtros e consultas.
- Refatores simples podem melhorar a legibilidade do código sem alterar seu comportamento.
- Verifique todos os pontos de consumo de dados ao mudar contratos implícitos entre frontend e backend.
