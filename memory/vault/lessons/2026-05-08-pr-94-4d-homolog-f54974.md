## O que aconteceu
Este PR ajusta a UI do **Chatboard Panel** removendo a ação **“Salvar como…”** na listagem/visualização de documentos/anexos, desabilitando o botão para o usuário.

## Decisão / Solução
A decisão foi comentar o código HTML em vez de removê-lo, mantendo a possibilidade de reativação futura, mas gerando a necessidade de um tracking para evitar confusões.

## Lessons
- Sempre que desabilitar uma funcionalidade, considere documentar a razão e o plano de retorno para evitar dívida técnica.
- Avalie o impacto na experiência do usuário ao remover opções, mesmo que sejam problemáticas.
- Teste as alterações em múltiplos navegadores para garantir consistência na funcionalidade.
