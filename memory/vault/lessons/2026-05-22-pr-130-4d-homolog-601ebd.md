## O que aconteceu
Foi realizado um ajuste no fluxo de upsert de contatos no Supabase, permitindo que o sistema atualize registros existentes ao invés de lançar um erro quando um contato já existe.

## Decisão / Solução
A estratégia de persistência foi alterada para utilizar `update` quando um contato já existe e `insert` quando não existe, eliminando a necessidade de uma consulta redundante.

## Lessons
- Sempre valide se o critério de busca está correto para evitar atualizações indevidas.
- Considere a idempotência ao modificar fluxos de atualização para evitar erros em integrações.
- Remova consultas redundantes para simplificar o código e melhorar a performance.
