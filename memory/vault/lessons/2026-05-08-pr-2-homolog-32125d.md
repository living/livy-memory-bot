## O que aconteceu
Este PR adiciona um novo endpoint para obter estatísticas de uma pasta do Google Drive, incluindo tamanho total, quantidade de arquivos/pastas e lista de arquivos com tamanho formatado. Também amplia o modelo `FileRef` para incluir informações de tamanho e prepara a estrutura para contagem de páginas, além de realizar um refactor no módulo do Pinecone VectorDB.

## Decisão / Solução
Foi decidido criar um endpoint `GET /v1/import/:projectId/folderStats?folderId=...` para retornar métricas da pasta, enriquecendo o modelo `FileRef` com novos campos que permitem exibir informações detalhadas sobre os arquivos. O refactor no Pinecone VectorDB focou na legibilidade e na prevenção de duplicação de dados.

## Lessons
- Sempre verificar se novos endpoints estão protegidos adequadamente para evitar exposição indesejada.
- Ao implementar novas funcionalidades que dependem de dados de arquivos, garantir que todos os métodos necessários estejam integrados para evitar retornos nulos.
- Manter a documentação e os testes atualizados com as alterações no código para garantir a continuidade e a qualidade do projeto.
