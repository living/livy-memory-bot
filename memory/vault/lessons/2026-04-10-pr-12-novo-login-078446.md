## O que aconteceu
Foi criado um novo sistema de login, mas houve dificuldades em acessar o diff das mudanças devido a falhas nas chamadas ao endpoint, resultando em erros 404. Sem o diff, não foi possível analisar as alterações e gerar a documentação necessária.

## Decisão / Solução
A solução proposta foi solicitar o diff de uma das três maneiras: através de um link público do GitHub, colando o conteúdo do diff no chat, ou utilizando a API do GitHub para acessar os metadados e arquivos necessários.

## Lessons
- Sempre forneça acesso ao diff de um PR para facilitar a análise e documentação das mudanças.
- Evite compartilhar credenciais sensíveis em URLs, pois isso pode comprometer a segurança do repositório.
- Utilize a API do GitHub como uma alternativa para acessar informações de PRs quando o acesso direto não for possível.
