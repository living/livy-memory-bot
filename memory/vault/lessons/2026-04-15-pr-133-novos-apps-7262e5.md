## O que aconteceu
Este PR atualiza a semeadura de dados iniciais da tabela `Application` para incluir novas aplicações/ambientes no sistema, adicionando 3 novos registros no array `applicationData`.

## Decisão / Solução
Foi decidido que o sistema deve reconhecer novos “targets” que podem ser utilizados em cadastros e filtros, garantindo que essas novas aplicações existam automaticamente em novas instalações.

## Lessons
- Ao adicionar novos registros em uma tabela, é importante considerar como esses dados serão inseridos em ambientes já existentes.
- Implementar um mecanismo de migração ou uma rotina idempotente pode evitar inconsistências entre diferentes ambientes.
- Testes devem ser realizados em cenários de banco de dados limpo e existente para garantir que o comportamento do sistema esteja conforme o esperado.
