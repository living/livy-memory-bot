## O que aconteceu
Esta tarefa representa a substituição do shell atual (SideNav/TopBar/AppLayout) pela nova estrutura visual definida no design de referência, incluindo componentes e funcionalidades específicas.

## Decisão / Solução
A decisão foi implementar a nova estrutura visual utilizando CSS do design de referência, garantindo que os componentes React aplicassem as classes corretamente. Além disso, foi adicionado um novo endpoint para alimentar o status card, e a implementação do `PingAsync` na interface Hydra foi realizada.

## Lessons
- A importância de seguir um design de referência para garantir a consistência visual e funcionalidade.
- A necessidade de validar pré-requisitos, como o healthcheck do Hydra, antes de avançar em tarefas críticas.
