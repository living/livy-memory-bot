## O que aconteceu
Este PR faz uma limpeza e ajuste de dados estáticos, reduzindo a lista de países para apenas cinco e adicionando novas áreas e classificações de Touchpoint. Essa mudança foi feita para simplificar a interface e melhorar a usabilidade.

## Decisão / Solução
Decidiu-se por uma refatoração que inclui a redução da lista de países e a adição de novas categorias no banco de dados. Essa abordagem visa otimizar a experiência do usuário e garantir que apenas informações relevantes sejam apresentadas.

## Lessons
- Sempre documentar o motivo de mudanças significativas na estrutura de dados, como a redução da lista de países, para facilitar a compreensão futura.
- Ao realizar alterações que podem afetar a usabilidade, como a lista de países, é crucial testar todos os fluxos que dependem dessa informação.
- Implementar uma verificação de idempotência mais robusta no seed do banco de dados para evitar problemas em ambientes com dados legados.
