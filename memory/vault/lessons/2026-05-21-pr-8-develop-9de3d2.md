## O que aconteceu
Este PR melhora a robustez e idempotência das migrações e execução de SQL, além de adicionar uma migração para garantir a existência das tabelas de job de download no Supabase. Também ajusta o fluxo de criação de configs para evitar registros “meio-criados” quando a persistência falha.

## Decisão / Solução
Foi decidido implementar um rollback na criação de configs para evitar que registros inválidos sejam mantidos. As migrações foram alteradas para serem idempotentes, permitindo reexecuções seguras. O parser de SQL foi ajustado para ignorar delimitadores dentro de strings, reduzindo falhas na execução.

## Lessons
- Implementar rollback em operações críticas para evitar registros incompletos que possam causar problemas futuros.
- Garantir que as migrações sejam idempotentes para facilitar reexecuções sem erros.
- Ajustar parsers de SQL para lidar com casos especiais, como strings que contêm delimitadores, para evitar falhas na execução.
