## O que aconteceu
Este PR centraliza e atualiza o link do “Infra Dashboard” para um novo endpoint através de uma constante compartilhada. Também inclui ajustes de formatação na `HomePage` para melhorar a legibilidade.

## Decisão / Solução
Foi decidido centralizar o link do Infra Dashboard em um único arquivo de configuração, evitando duplicação e facilitando a manutenção. Além disso, o controle de acesso foi ajustado para garantir que todas as partes do sistema apontem para o mesmo recurso.

## Lessons
- Centralizar URLs em um único arquivo de configuração melhora a manutenção e reduz a probabilidade de erros.
- Garantir que as permissões de acesso sejam consistentes com as URLs utilizadas é crucial para a segurança e funcionalidade do sistema.
- Pequenos ajustes de formatação podem ter um impacto positivo na legibilidade e na qualidade do código.
