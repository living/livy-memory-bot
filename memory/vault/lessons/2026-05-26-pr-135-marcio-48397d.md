## O que aconteceu
Foi implementado novos módulos **Condomínio** e **Garantidora** na API utilizando NestJS. Foram criados endpoints privados para listar e buscar condomínios, além de realizar operações CRUD para garantidoras e gerenciar vigências de garantidoras por condomínio, incluindo validação de conflitos de datas. A camada de dados foi expandida para suportar essas novas entidades.

## Decisão / Solução
A decisão foi de criar novos módulos e endpoints que permitissem a gestão de condomínios e garantidoras, com validações rigorosas para evitar conflitos de datas. A implementação foi feita de forma a garantir que a camada de dados fosse capaz de suportar as novas funcionalidades, utilizando Supabase para a implementação completa e Baserow como uma solução temporária.

## Lessons
- Sempre validar as entradas e regras de negócio para evitar inconsistências, como sobreposição de datas em vigências.
- Padronizar o tratamento de erros para facilitar a manutenção e o entendimento do sistema.
- Documentar adequadamente as novas rotas e configurações para garantir que todos os desenvolvedores possam utilizar as novas funcionalidades sem confusão.
