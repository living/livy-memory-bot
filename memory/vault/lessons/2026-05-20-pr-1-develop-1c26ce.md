## O que aconteceu
Este PR adiciona CI/CD do `dashboard-ui` (Next.js) para deploy automatizado no Azure App Service, com dois workflows do GitHub Actions (Homolog e Produção). Ele também ajusta o Next.js para `output: 'standalone'`, permitindo empacotar a aplicação como artefato autocontido e publicar no App Service via Publish Profile.

## Decisão / Solução
Foi decidido automatizar os deploys por ambiente, evitando a necessidade de build/instalação no Azure. O workflow foi padronizado para instalar dependências, realizar o build, copiar assets estáticos, compactar e fazer o deploy no Azure.

## Lessons
- Sempre verifique se os assets estáticos estão sendo copiados corretamente para evitar que o aplicativo quebre após o deploy.
- É crucial configurar os secrets e ambientes no GitHub para garantir que os deploys funcionem corretamente.
- Utilize o modo `standalone` do Next.js para simplificar o processo de deploy e reduzir a necessidade de configuração no ambiente de produção.
