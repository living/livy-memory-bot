## O que aconteceu
Foram realizados ajustes na tela de **Condomínios** com o objetivo de melhorar a experiência do usuário (UX) e evitar estados visuais incorretos. As principais mudanças incluem a remoção da clicabilidade do card inteiro e a adição de um botão explícito para **editar**, além de um estado de carregamento específico para a listagem de **Empresas de Cobrança**.

## Decisão / Solução
Decidiu-se por uma ação de edição mais clara, onde o card não é mais clicável por inteiro, reduzindo cliques acidentais. Um botão com ícone de lápis foi adicionado para abrir os detalhes. Além disso, a separação do controle de carregamento foi implementada para evitar estados visuais confusos durante a busca de dados.

## Lessons
- Sempre que possível, torne as ações do usuário mais explícitas para evitar confusões e cliques acidentais.
- Separe estados de carregamento para diferentes componentes para garantir que a UI reflita corretamente o estado atual da aplicação.
- Revise as mudanças de usabilidade com os usuários para garantir que as alterações atendam às expectativas e não causem frustrações.
