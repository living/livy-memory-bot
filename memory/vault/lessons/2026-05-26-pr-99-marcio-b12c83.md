## O que aconteceu
Este PR evolui o módulo Chatboard (CRM) ao adicionar duas novas áreas: Condomínios e Empresas de cobrança (Garantidoras). Foram implementadas telas, serviços, rotas e resolvers para a carga inicial dos dados, além de ajustes na navegação lateral e novos ícones.

## Decisão / Solução
Foi decidido expandir o CRM para incluir funcionalidades de gerenciamento de condomínios e empresas de cobrança, criando novas rotas e resolvers para otimizar o carregamento de dados. A navegação foi ajustada para incluir novos menus e ícones, e a ação de "Excluir" foi alterada para "Arquivar".

## Lessons
- Sempre validar a consistência do ambiente ao trabalhar com múltiplas rotas, evitando hardcoding de valores como 'default'.
- Implementar resolvers para pré-carregar dados pode melhorar a experiência do usuário ao navegar entre páginas.
- A documentação e os testes devem ser atualizados sempre que novas funcionalidades forem adicionadas, garantindo que todos os aspectos do sistema estejam cobertos.
