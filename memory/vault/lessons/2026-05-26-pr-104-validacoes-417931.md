## O que aconteceu
Este PR substitui os inputs nativos de data por Angular Material Datepicker na tela de Condomínio (Chatboard) e configura a localização pt-BR para o componente de data. O objetivo é melhorar a experiência do usuário e garantir a padronização do formato de data enviado/salvo.

## Decisão / Solução
Foi adotado o MatDatepicker para os campos de Data Início e Data Fim, com a configuração do locale para pt-BR. A normalização da data é feita utilizando a biblioteca moment, garantindo que o valor seja sempre formatado como `YYYY-MM-DD`.

## Lessons
- Sempre que possível, utilize componentes de UI consistentes, como o Angular Material, para melhorar a experiência do usuário.
- Ao implementar mudanças que afetam o binding de dados, documente as alterações para evitar confusões futuras na equipe.
- Considere a padronização de bibliotecas de manipulação de datas no projeto para evitar dependências desnecessárias e aumentar a coesão do código.
