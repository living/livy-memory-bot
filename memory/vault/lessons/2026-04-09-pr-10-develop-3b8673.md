## O que aconteceu
Foi realizado um ajuste nos workflows do GitHub Actions para remover a atualização global do npm para a versão 11.x durante o build. Essa mudança visa evitar falhas e intermitências nos builds, mantendo o restante do processo intacto.

## Decisão / Solução
A decisão foi remover a execução do comando `npm install -g npm@11.x` nas pipelines de homolog e master, permitindo que o workflow utilize a versão de npm que vem com o Node configurado no ambiente, o que torna o pipeline mais previsível e alinhado ao toolchain padrão.

## Lessons
- Remover dependências de versões específicas de ferramentas no CI/CD pode aumentar a estabilidade e previsibilidade do ambiente de build.
- Para garantir a consistência do ambiente, é preferível fixar a versão do Node ao invés de instalar uma versão específica do npm globalmente.
- É importante validar o impacto das mudanças no comportamento do build, especialmente se houver dependências de versões específicas de ferramentas.
