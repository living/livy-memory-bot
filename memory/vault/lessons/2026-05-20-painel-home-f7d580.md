## O que aconteceu
Foi criado o `PainelPage` com três variantes por perfil, utilizando novos endpoints no backend e implementando melhorias de cache e segurança.

## Decisão / Solução
A decisão foi substituir o `VistoriasPage` pela nova `PainelPage`, que é alimentada por quatro novos endpoints e utiliza um sistema de cache para otimizar a performance.

## Lessons
- A implementação de cache com `IMemoryCache` é crucial para melhorar a performance em aplicações que dependem de dados dinâmicos.
- A validação de audit log com `InMemorySink` do Serilog é uma boa prática para garantir a segurança e a integridade dos dados em sistemas multi-tenant.
