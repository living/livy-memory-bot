## O que aconteceu
Este PR ajusta o workflow de CI/CD da Azure Function **retailaudit-process-func** para adicionar **controle de concorrência** nas execuções do GitHub Actions, evitando múltiplos deploys/builds simultâneos para o mesmo pipeline.

## Decisão / Solução
Foi adicionada a configuração de `concurrency` no workflow, garantindo que apenas uma execução do workflow esteja ativa por branch/ambiente. Isso melhora a previsibilidade do pipeline e reduz o risco de conflitos e condições de corrida.

## Lessons
- Implementar controle de concorrência em workflows pode prevenir problemas de deploys simultâneos e garantir que apenas a versão mais recente seja implantada.
- É importante considerar a definição do `concurrency.group` para evitar limitações em cenários onde execuções paralelas são necessárias.
- Testes rigorosos devem ser realizados para validar o comportamento do pipeline após a implementação de novas configurações de concorrência.
