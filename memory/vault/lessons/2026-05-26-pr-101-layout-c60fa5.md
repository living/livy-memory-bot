## O que aconteceu
Este PR melhora a apresentação visual dos cards de Condomínio, adicionando avatar ou fallback com iniciais, e ajusta o layout na tela de Garantidora. A motivação principal foi melhorar a experiência do usuário e a identificação visual, além de evitar ações indevidas.

## Decisão / Solução
Foi decidido incluir um avatar nos cards de Condomínio, utilizando uma lógica que renderiza uma imagem se disponível ou iniciais caso contrário. Além disso, a área de ações na tela de Garantidora foi ajustada para ocupar toda a largura do botão de editar, e a ação de excluir foi comentada no template.

## Lessons
- Sempre validar se os dados utilizados para fallback são consistentes para evitar problemas de usabilidade.
- Considere implementar controles de permissão em vez de desativar funcionalidades via comentários no código.
- Testes de layout responsivo são essenciais para garantir a usabilidade em diferentes dispositivos.
