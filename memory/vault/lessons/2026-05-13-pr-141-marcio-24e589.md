## O que aconteceu
Este PR introduziu uma nova área de Gerenciamento de SKUs, incluindo funcionalidades de CRUD, upload e gestão de imagens, além de um wizard para integração com APIs externas. Também foram feitas atualizações em permissões, navegação, schema do banco e documentação técnica.

## Decisão / Solução
Foi decidido implementar um novo domínio para SKUs, que inclui novas tabelas e integrações com APIs externas. O wizard foi projetado para facilitar a configuração de requests encadeados e mapeamento de campos, garantindo uma experiência de usuário alinhada com os padrões do projeto.

## Lessons
- A execução dinâmica de código, como em `applyTransform()`, deve ser cuidadosamente revisada para evitar riscos de segurança, especialmente em relação a quem pode gravar scripts.
- A duplicidade de rotas entre App Router e Pages Router pode causar conflitos e deve ser verificada no ambiente do projeto.
- É importante validar as permissões e o impacto das migrações de colunas em runtime para garantir a consistência com os ambientes existentes.
