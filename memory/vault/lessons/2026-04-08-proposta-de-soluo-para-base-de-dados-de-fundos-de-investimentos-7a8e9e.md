## O que aconteceu
Foi proposta uma solução para a criação de uma base de dados centralizada para o Patrimônio Líquido (PL) dos Fundos de Investimentos, visando melhorar a gestão e o acesso às informações.

## Decisão / Solução
A decisão foi implementar uma base de dados centralizada que permita a integração e a consulta eficiente dos dados dos Fundos de Investimentos, tanto da B3 quanto do mercado de balcão.

## Lessons
- A centralização de dados pode melhorar a eficiência e a acessibilidade das informações financeiras.
- É crucial considerar a integração de diferentes fontes de dados para uma solução robusta.
