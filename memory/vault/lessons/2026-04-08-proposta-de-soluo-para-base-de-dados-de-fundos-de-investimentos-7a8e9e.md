## O que aconteceu
Foi proposta uma solução para a criação de uma base de dados centralizada para o Patrimônio Líquido (PL) dos Fundos de Investimentos, visando melhorar a gestão e o acesso às informações.

## Decisão / Solução
A decisão foi implementar uma base de dados centralizada que permitirá a integração e o acesso mais eficiente às informações dos Fundos de Investimentos, tanto da B3 quanto do mercado de balcão.

## Lessons
- A centralização de dados facilita a gestão e a análise das informações, promovendo uma tomada de decisão mais informada.
- A integração de diferentes fontes de dados pode reduzir a redundância e aumentar a confiabilidade das informações disponíveis.
