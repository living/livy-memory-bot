## O que aconteceu
Foi proposta a replicação dos arquivos gerados no ECB CSNET para o diretório ECB-GERAL, com o objetivo de facilitar o acesso das equipes de negócio aos dados, permitindo que baixem diretamente dos diretórios.

## Decisão / Solução
A decisão foi implementar a replicação dos arquivos para que as equipes não precisem mais zipar e enviar por e-mail, além de possibilitar o uso das bases em futuros Dashboards. Foi solicitado que o caminho para a configuração fosse definido no arquivo adapters.PROD.config.

## Lessons
- A replicação de arquivos pode otimizar o acesso a dados importantes para as equipes de negócio.
- Automatizar processos de transferência de arquivos reduz a necessidade de intervenções manuais, aumentando a eficiência.
