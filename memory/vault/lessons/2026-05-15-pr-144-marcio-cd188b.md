## O que aconteceu
Este PR introduz um novo endpoint público para consulta de SKUs com filtros dinâmicos e paginação, além de mover operações usadas pela UI para um novo endpoint autenticado. Também foram feitos ajustes visuais relevantes em componentes da tela de SKUs.

## Decisão / Solução
Foi decidido separar as responsabilidades entre a API pública e a API da UI, implementando um novo mecanismo de busca e paginação no backend. Um controle de feature foi adicionado para habilitar a configuração de integração externa, e ajustes de UI/UX foram realizados para melhorar a experiência do usuário.

## Lessons
- A separação de responsabilidades entre APIs pode aumentar a segurança e a manutenibilidade do sistema.
- Implementar filtros dinâmicos na API melhora a flexibilidade e a usabilidade para os consumidores.
- Ajustes visuais e de UX são essenciais para garantir que a interface do usuário seja intuitiva e responsiva.
