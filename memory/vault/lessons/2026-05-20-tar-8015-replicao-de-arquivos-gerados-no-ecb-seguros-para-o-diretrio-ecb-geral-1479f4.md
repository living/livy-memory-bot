## O que aconteceu
Foi identificada a necessidade de replicar os arquivos gerados no ECB Seguros para o diretório ECB-GERAL, permitindo que os times de negócio acessem os dados diretamente, sem a necessidade de zipar e enviar por e-mail.

## Decisão / Solução
A solução proposta foi configurar o caminho de replicação dos arquivos no sistema, garantindo que os dados estejam disponíveis para uso em dashboards futuros e facilitando o acesso das equipes.

## Lessons
- A centralização do acesso a dados melhora a eficiência dos times de negócio.
- A automação do processo de replicação de arquivos reduz a necessidade de intervenções manuais e o risco de erros.
