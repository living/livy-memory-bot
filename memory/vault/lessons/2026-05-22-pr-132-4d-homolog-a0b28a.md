## O que aconteceu
Este PR ajusta o fluxo de busca/criação de contatos no Supabase para evitar consultas com identificadores inválidos e melhorar a confiabilidade do retorno após `insert`. As mudanças incluem melhorias na validação de pré-condições, ajuste de critério de busca e o `insert` agora retorna dados com um log de alerta quando o Supabase não retorna registros.

## Decisão / Solução
Foi decidido evitar consultas desnecessárias no Supabase, alterando o critério de busca de `cpf_cnpj` para `id`, além de garantir que o `insert(contact)` retorne dados ao utilizar `select()`. Também foi adicionado um log de alerta para melhorar a observabilidade em casos de inserções silenciosas.

## Lessons
- Sempre valide se os identificadores utilizados nas consultas correspondem ao que se espera, para evitar inconsistências nos resultados.
- Utilize `insert().select()` para garantir que os dados inseridos sejam retornados, facilitando a integração com etapas subsequentes.
- Implemente logs de alerta para cenários onde os dados esperados não são retornados, ajudando na identificação de problemas relacionados a políticas de segurança ou conflitos.
