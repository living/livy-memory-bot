## O que aconteceu
A reunião de cadência 4D discutiu várias questões relacionadas ao uso de OCR e integração com serviços de nuvem, incluindo a necessidade de mudar de Adobe OCR para Google Cloud Vision API devido a limitações de cota.

## Decisão / Solução
Foi decidido adotar o Google Cloud Vision API como alternativa ao Adobe OCR para reduzir custos e implementar melhorias na interface do sistema.

## Lessons
- A escolha de ferramentas deve considerar não apenas o custo, mas também a capacidade de atender à demanda inicial.
- A implementação de melhorias na interface do usuário pode aumentar a eficiência e a satisfação do cliente.
