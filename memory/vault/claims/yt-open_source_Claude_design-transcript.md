## Resumo (TLDR)

Vídeo de Jack Roberts comparando **Huashu Design** (skill open-source) vs **Claude Design** (ferramenta nativa).

### Huashu Design
- Repositório open-source que replica o Claude Design como skill para Claude Code
- 1 skill com 20 markdown files internos (mini-skills), components/assets, e executable toolchain
- Custo: ~70K tokens por landing page (~130K por sessão); <1% do uso semanal
- Velocidade: ~11 min vs 3 min do Claude Design nativo

### Comparações

| Métrica | Claude Design | Huashu Design |
|---|---|---|
| Custo por landing page | ~15% do limite semanal | ~1% (170K tokens) |
| Velocidade | 3 min | 11 min |
| Qualidade (raw) | Similar | Quase igual |
| Tweaks | Mais opções (UI visual) | Comparable, menos granular |
| Design system | Consome ~30% do limite | Cria na hora com tokens |

### Resultados
- **Landing page raw**: Huashu ≈ Claude Design (mesmo nível)
- **Com design system**: Huashu quase igual, mas sem UI de desenho
- **Slide decks**: Huashu的优秀, com overlap mínimo corrigível com 1 prompt
- **Veredicto**: Huashu é alternativa real para quem não quer pagar $200/mês de limite

### Conclusão
- Claude Design ainda é melhor (UI visual, draw/comment, trabalho em equipe)
- Huashu é "mais do que suficiente" para uso individual
- Abrevia a "usage jail" do Claude Design
- Útil para: landing pages, slide decks, motion design, infographics
