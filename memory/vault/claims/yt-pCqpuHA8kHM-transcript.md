## Resumo (TLDR)

O vídeo apresenta um sistema de construção de **"Super Skills"** para Claude Code baseado nos princípios de Andre Karpathy:

1. **4 Pilares Karpathy** — think before coding, simplicity first, surgical changes, goal-driven execution
2. **Super Skills** vs Utility Skills** — Super skills têm memória infinita, usam ferramentas específicas e melhoram com feedback
3. **3Camadas de Memória:**
   - Bucket 1: wrap-up de conversas → memória de longo prazo (Pinecone)
   - Bucket 2: knowledge base (imutável — vídeos, posts, livros)
   - Bucket 3: profile/strategy (mutável — arquivo MD lido toda sessão)
4. **4 tiers de skill:**
   - Tier 1: criar skill com intention + outcome (via skill creator)
   - Tier 2: dar ferramentas certas (connectors: Firecrawl, Gmail, Zapier, MCP)
   - Tier 3: memória operacional (Obsidian ou Pinecone)
   - Tier 4: refinement loop (skill executa → usuário grade → modelo melhora)
5. **Conectores Mentionados:** Firecrawl MCP, Gmail, Zapier, Claude Connectors
