KABA + Hydra Foundation
⚠️ Status: Fase de design e documentação. Hydra-Flow ainda não tem código de runtime merged. O repositório é predominantemente documental (specs, arquitetura, processo). A implementação do monorepo e plugins está em construção — PR #8 (Initial - Core Code and Plugins) de estevesm é a primeira contribuição de código real.

O que é

Hydra-Flow será um hub extensível plugin-first para operar comunicação, mensageria e processos em ambiente event-driven e multi-tenant.

Diferente do SVD (implementação concreta), Hydra-Flow é um projeto de fundação — focado em definir a arquitetura, padrões e processo antes de implementar runtime.
