## 1. Motivação

**Problema:** O SSOT não justifica a complexidade. E Trello não é fonte de decisões — é fonte de controle operacional.

| Fato | Implicação |
|---|---|
| 99.9% das 2,221 claims SSOT têm `topic_id=null` | Routing nunca funcionou |
| Trello DONE cards são logs de task completion | Não são decisões — são **estado operacional** |
| ~55 decisões TLDV reais por semana | Ouro — extrair diretamente |
| GitHub PRs têm corpo com decisões técnicas | Ouro — extrair diretamente |
| **Intersecção Trello + GitHub + TLDV** | **O valor real — mesmo item em 3 plataformas** |

**O que importa em cada fonte:**

| Fonte | Valor real |
|---|---|
| **TLDV** | Decisões de reunião — "foi decidido que...", aprovações, alinhamentos |
| **Trello** | **Controle operacional** — o que está doing/done/backlog, timestamps, plugin de horas, PRs vinculados |
| **GitHub** | Decisões técnicas em PR bodies, approvals, code review |

**Decisão:** QW-2 consulta RAW diretamente. Cada fonte extrai o que tem de melhor. A **intersecção** é o valor diferenciador.

## 3. QW-2 — RAW → Topic File Pipeline

### 3.1 Trello — Controle Operacional (não decisões)

**O que extrair de cada card Trello:**

```python
{
    "source_ref": "trello:card_id",
    "board_name": "BAT/ConectaBot",
    "list_name": "Concluído 🎉",       # doing / done / backlog
    "card_name": "Deploy UAT - Voice RLSE0109469",
    "moved_to_current_list_at": "2026-05-20T14:30:00Z",
    "hours_logged": 4.5,               # do plugin de horas (se existir)
    "github_pr_url": "https://github.com/living/livy-forge-platform/pull/42",
    "github_pr_number": 42,            # extraído da URL
    "last_activity": "2026-05-20T14:30:00Z",
    "source": "trello",
}
```

**Por que DONE cards são dados válidos:**
- `"Card 'X' foi concluído"` → **snapshot de status** (quando entrou em done)
- Plugin de horas → **tracking real de effort**
- GitHub PR link no card → **intersecção** com GitHub

**O que NÃO é ruído:**
- Cards em qualquer lista (BACKLOG, doing, done) — todos são dados operacionais
- Placeholder cards sem descrição — filtro por `card_name` length

**Filtros para Trello:**
```python
def trello_card_passes_filter(card: dict) -> bool:
    # 1. Card sem nome útil
    if len(card.get("card_name", "")) < 10:
        return False
    # 2. Card sem qualquer dado útil (sem list_name, sem timestamp)
    if not card.get("list_name") or not card.get("last_activity"):
        return False
    return True
```

**Sem `DONE_CARD_RE` para Trello.** DONE cards passam — são dados operacionais.

**Filtros para TLDV:**
- Length < 50 chars → skip
- Confidence < 0.75 → skip
- "sem decisões registradas" → skip
- Status meeting com confidence < 0.90 → skip (override se ≥ 0.90)

### 3.4 Intersecção (Cross-Platform)

**O valor diferenciador.** Mesmo item aparece em múltiplas plataformas:

```
Trello card: "Deploy UAT - Voice RLSE0109469"
GitHub PR:   "feat: deploy voice to UAT #42" (mergeado)
TLDV meeting: "Validamos o deploy de UAT voice"
```

**Implementação:**
```python
def find_intersections(trello_items: list, github_items: list, tldv_items: list) -> list:
    """Encontra items que aparecem em múltiplas plataformas."""
    intersections = []
    for item in trello_items + github_items + tldv_items:
        platforms = []
        if item.get("github_pr_url"):
            platforms.append("github")
        if item.get("trello_card_url"):
            platforms.append("trello")
        if item.get("source") == "tldv":
            platforms.append("tldv")
        if len(platforms) >= 2:
            intersections.append({**item, "cross_platform": platforms})
    return intersections
```

**Output de intersecção** vai para topic files com prefixo `🔗`:
```markdown
### 🔗 2026-05-20 — Intersecção cross-platform

> Deploy UAT - Voice RLSE0109469

- **Trello:** BAT/ConectaBot → Concluído em 2026-05-20 | 4.5h logadas
- **GitHub:** `living/livy-forge-platform#42` mergeado em 2026-05-19
- **TLDV:** "Validamos o deploy de UAT voice" — reunião 2026-05-19
```

## 5. Cursor per Source

### Trello (all 28 boards)

```python
def fetch_trello_all_boards(lookback_days: int = 30) -> list[dict]:
    """
    Busca todos os boards do token Trello (sem allowlist).
    Retorna cards atualizados desde cursor, com plugin data.
    """
    boards = trello_api.list_my_boards()  # usa token → todos os boards
    all_cards = []
    for board in boards:
        cursor_key = f"trello_{slug(board['name'])}"
        cursor = QWCursor(cursor_key).read()
        cards = trello_api.get_cards_since(board['id'], since=cursor)
        for card in cards:
            card['_board_name'] = board['name']
            # Extrair plugin data
            card['_hours_logged'] = extract_hours_plugin(card.get('desc', ''))
            card['_github_pr_url'] = extract_github_url(card.get('desc', ''))
            all_cards.append(card)
        if cards:
            update_cursor(cursor_key, max(c['dateLastActivity'] for c in cards))
    return all_cards
```
